> 版本：v0.1（草稿）· 日期：2026-10-26

---

## 1. 项目定位

**一句话：一个「AI 短剧生产线」平台 —— 用户像搭积木一样用节点编排整部短剧的制作流程，所有 AI 能力走云端 API，平台本身不跑本地 GPU。**

- 对标：LiblibAI（云端创作平台）+ ComfyUI（可视化节点工作流）
- 差异化：**短剧专用语义化节点 + 鲸剧方法论内置提示词（可编辑）+ 全 API 节点**
- 与现有管线关系：把你已有的「剧本→四视图→分镜图→分镜视频→拼接」流程产品化、可视化、开放

**核心技术决策（已确认）：**
- 前端画布：**React Flow**
- 后端：**Java / Spring Boot**
- 节点：**全部走云端 API**（LLM / 文生图 / 图生图 / 视频），平台不跑本地 GPU
- 提示词：**内置鲸剧（jingju-skills）模板，每个节点参数可编辑**

## 2. 鲸剧方法论固化为节点

鲸剧技能（VM `~/.codex/skills/jingju-skills/`）的 10 阶段流程 → 固化为工作流节点：

| 鲸剧阶段 | 对应节点 | 节点类型 |
|---|---|---|
| 1. 项目设定 | **项目设定节点** | LLM |
| 2. 剧本大纲 | **剧本大纲节点** | LLM |
| 3. 角色设定 | **角色卡节点** | LLM |
| 4. 角色参考图 | **角色参考图节点** | 文生图 |
| 5. 分集剧本 | **分集剧本节点** | LLM |
| 6. 分镜脚本 | **分镜脚本节点** | LLM |
| 7. 图片提示词 | **分镜图节点**（内置 7 段式提示词） | 图生图 |
| 8. 图片生成/选择 | （合并进分镜图节点，输出多版本） | — |
| 9. 图生视频提示词 | **图生视频节点** | 视频 |
| 10. 视频生成/选择 | （合并进图生视频节点） | — |

**鲸剧核心原则 → 平台规则：**
- 「每阶段必须用户确认」→ **运行拦截**：上游节点输出未 `approved/selected`，下游节点黄色警告不可运行
- 「角色锁定词防漂移」→ **角色卡节点输出的 `lock_prompt` 自动注入下游所有图生图/视频节点**
- 「少抽卡」→ 每个图像节点输出多版本（v1/v2...），用户 `select` 后才允许进入下一阶段
- 「提示词可改」→ 每个节点内置模板为默认值，参数面板逐段可编辑，保存为自定义版本

## 4. 节点清单（第一期）

### 4.1 LLM 创作节点（调 LLM API）

| 节点 | 输入 | 输出 | 内置模板（鲸剧） |
|---|---|---|---|
| **项目设定** | 用户文字描述 | project-state JSON | 剧名/环境/类型/剧型/画风/集数/时长/爽点/情绪基调 |
| **剧本大纲** | project-state | outline JSON | 一句话简介/世界观/冲突/人物关系/三幕/分集大纲/爽点/钩子 |
| **角色卡** | project-state + outline | character-card JSON | 基础设定9字段+外貌10字段+角色锁定词+禁止变化项+参考图提示词 |
| **分集剧本** | outline + character-card | 单集剧本 md | 本集目标/情绪曲线/爽点/钩子/场景正文 |
| **分镜脚本** | 剧本 + character-card | shot-card JSON | 11字段（shot_id/时长/场景/角色/目的/景别/构图/动作/字幕/情绪/转场） |

### 4.2 图像节点（调图像 API）

| 节点 | 输入 | 输出 | 内置模板（鲸剧） |
|---|---|---|---|
| **角色参考图** | character-card.lock_prompt | 参考图多版本 | `{锁定词}, 纯白背景, 单人, 不拿道具, 多视角(正特写+正全身+侧+背)` + 负面词库 |
| **分镜图** | shot-card + 参考图 + 场景 | 分镜图多版本 | 7段式：`{角色锁定词}+{场景}+{构图}+{情绪}+{动作}+{画风}+{质量}` + 负面词 |

### 4.3 视频节点（调视频 API）

| 节点 | 输入 | 输出 | 内置模板 |
|---|---|---|---|
| **图生视频** | 已 selected 的分镜图 + 视频提示词 | 视频多版本 | `保持原图角色一致 + 动作 + 表情变化 + 镜头运动 + 环境动效 + 节奏` + 负面词 |

### 4.4 工具/流程节点

| 节点 | 说明 |
|---|---|
| **素材节点** | 上传/选择图片（角色参考图/场景/道具）作为输入 |
| **LLM 通用节点** | 自由写 prompt 调任意大模型，不套模板（提示词可改的兜底） |

## 5. 提示词模板引擎（核心设计）

**目标：鲸剧提示词内置 + 可编辑。**

### 5.1 模板结构（JSON）

```json
// node-templates/character-ref.json（角色参考图节点）
{
  "nodeType": "character_ref",
  "name": "角色参考图",
  "version": "1.0",
  "sections": [
    {
      "key": "lock_prompt",
      "label": "角色锁定词",
      "source": "upstream",        // 从角色卡节点自动注入
      "editable": true             // 可改（改了只影响本节点）
    },
    {
      "key": "background",
      "label": "背景",
      "default": "纯白背景, 干净统一底色, 单人角色设定图, 不拿道具, 无复杂场景",
      "editable": true
    },
    {
      "key": "views",
      "label": "视角",
      "default": "多视角, 从左到右: 正面特写, 正面全身, 侧面, 背面",
      "editable": true
    },
    {
      "key": "style",
      "label": "画风",
      "default": "半写实国风仙侠",
      "editable": true
    }
  ],
  "negative_prompt": {
    "default": "different face, different hairstyle, different outfit, props, handheld object, complex background, messy background, extra people",
    "editable": true
  },
  "params": {
    "model": "agent-plan/doubao-seedream-5-0-pro",
    "size": "1536x1024",
    "n": 2
  }
}
```

### 5.2 运行时 prompt 组装

```
final_prompt = join(sections)  // 各 section 值（上游注入 or 默认 or 用户改）
             + negative_prompt
组装后传给 API 节点执行
```

### 5.3 变量注入

- `source: "upstream"` 的 section：运行时从上游节点输出取值（如角色卡的 `lock_prompt`）
- 取不到 → 用 default 值 → 都没有则黄色警告要求用户手填
- 用户改过的值 > 上游注入值 > 默认值

### 5.4 模板管理

- **内置模板**：随平台发布，只读（鲸剧原版）
- **我的模板**：用户改过的节点参数保存为自定义模板，可复用/版本化/恢复默认
- **共享模板**（二期）：工作流/节点模板市场

## 6. 状态机

```
draft ──(用户确认)──► approved ──(select版本)──► selected ──(锁定)──► locked
  ▲                      │
  └────(修改/revision)───┘
```

- 每个节点的输出资产带状态
- 运行拦截：上游未 `approved` → 下游节点禁止运行（黄色警告）
- 图像/视频多版本：全部 `draft`，用户 `select` 指定版本 → 下游用 selected 版本
- 资产 `locked` 后不可随意更改（防已确认资产被误改）

## 7. T1~T7 任务拆解

### T1：项目骨架 + 数据库模型（基础）
- Spring Boot 项目初始化（复用 ai-connecting 工程结构：JDK17+Maven+Vite）
- 数据库表：`workflows` / `nodes` / `edges` / `workflow_runs` / `node_runs` / `assets` / `templates`
- 用户系统基础（注册/登录/JWT，可复用 ai-connecting 模式）
- **验收**：项目能启动，建表成功

### T2：工作流 CRUD + 节点/连线存储
- `workflows` 表：id/名称/描述/画布 JSON（nodes+edges 序列化）/版本/创建者
- 保存/加载/列表/删除工作流 API
- 画布 JSON 结构 = React Flow 标准格式
- **验收**：前端画布能保存、刷新后恢复

### T3：提示词模板引擎
- 模板 JSON 定义（鲸剧 5 类 LLM + 2 类图像 + 1 类视频节点模板）
- 模板加载/渲染/变量注入（upstream > 用户改 > 默认）
- 节点参数面板数据结构（sections 渲染协议）
- **验收**：给定模板 JSON + 输入，能组装出 final_prompt

### T4：节点执行引擎 + LLM 节点
- DAG 拓扑排序（依赖满足才触发下游）
- 节点执行器框架（NodeExecutor 接口 + 各类型实现）
- LLM API 网关（调大模型：剧本/大纲/角色卡/分集剧本/分镜脚本）
- 任务队列：异步执行 + WebSocket 推送进度
- **验收**：画布上搭「项目设定→大纲→角色卡」能跑通，产出 JSON 资产

### T5：图像节点（角色参考图 + 分镜图）
- 图像 API 网关（复用 img_gen.py 的 agnes/seedream 通道：文生图+图生图多参考图）
- 角色参考图节点：四视图单图生成
- 分镜图节点：7 段式提示词 + 多参考图锁人物
- 多版本输出 + select 机制
- 429 限流退避重试
- **验收**：分镜图节点跑通，人物一致性可接受

### T6：视频节点（图生视频）
- 视频 API 网关（复用 video_gen.py 的 agnes-video 通道：480P 防漂移）
- 图生视频节点：内置一致性模板 + 多版本
- **验收**：selected 分镜图 → 视频生成成功

### T7：集成 + 部署 + 资产库
- 完整短剧模板工作流（项目设定→...→图生视频 一键搭好）
- 资产管理页（按项目分类浏览所有产出）
- 部署脚本（蓝绿部署，复用 ai-connecting deploy.sh 模式）
- 端到端验证：一条完整短剧管线跑通
- **验收**：从剧本到视频全流程可在画布上搭出并运行

## 8. 风险与开放问题

| 问题 | 影响 | 方案 |
|---|---|---|
| 视频 API 耗时数分钟，队列/超时 | T6 | 异步任务表 + 轮询/WebSocket |
| 多供应商 API 差异（参数/限流/审核） | T5/T6 | 复用 ai-connect 中转的转换器/退避经验 |
| 参考图转公网 URL | T5 | 复用 OSS 上传脚本 |
| 画布 JSON 与后端执行模型的映射 | T2/T4 | 定好 JSON schema，前后端对齐 |
| 视频生成成本高，如何计费 | T7 | 算力/会员体系二期，一期先不做计费 |
| 共享模板市场 | 二期 | 一期只做内置+我的模板 |
